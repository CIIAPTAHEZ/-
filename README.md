# Анализ рекламаций и операционного контроля

Локальное веб-приложение для автоматизации сбора, хранения, анализа и визуализации данных по рекламациям заказчиков и операционному контролю качества на производстве.

## Возможности

- 📥 **Импорт из Excel (.xlsx)** — лист «УТ_Рек» (претензии) и лист «База» (операционный контроль)
- 📋 **Журнал претензий** — поиск, фильтры, сортировка, пагинация, ручное редактирование
- 🔧 **Операционный контроль** — независимый раздел со всеми функциями работы с данными
- ⏱️ **Микролифт** — ручной ввод и статистика времени опускания микролифта: своя форма изделий (можно переименовывать/добавлять), типы замеров (сиденье/крышка/целое изделие), среднее, мин, макс, размах, история замеров
- 📊 **Аналитика** — столбчатые, круговые и линейные диаграммы, сводные таблицы, экспорт PNG, диаграмма среднего времени микролифта с планками min/max
- 📄 **Отчёты** — сводный PDF-отчёт за период (месяц / несколько месяцев / произвольные даты «с»-«по»), детализированные отчёты (Excel, CSV, PDF), акт рекламации
- 🗂️ **Файлы** — автоматическое создание папок претензий, открытие в проводнике, прикрепление файлов
- ⚙️ **Администрирование** — резервное копирование БД, журнал действий пользователей

## Требования

- Windows 10/11 (также работает на Linux/macOS)
- Python 3.10 или новее

## Установка и запуск

### Быстрый запуск (рекомендуется, Windows)

1. Дважды щёлкните файл **`start.bat`** в папке `claims_system`.
2. Откроется окно командной строки — приложение автоматически проверит зависимости, установит их при необходимости и запустит сервер.
3. Браузер откроется автоматически по адресу **http://127.0.0.1:5000**.
4. Для остановки приложения закройте окно командной строки.

> **Важно:** пока окно командной строки открыто — приложение работает. Не закрывайте его во время работы.

### Запуск вручную

```bash
# 1. Перейти в папку проекта
cd claims_system

# 2. Установить зависимости
pip install -r requirements.txt

# 3. Запустить приложение
python app.py
```

После запуска автоматически откроется браузер по адресу **http://127.0.0.1:5000**

## Импорт данных

1. Нажмите кнопку **«Импорт»** в верхней панели.
2. Выберите файл `.xlsx` с листами «УТ_Рек» и/или «База».
3. Программа автоматически:
   - сопоставит столбцы с полями БД;
   - проверит типы данных (даты, числа);
   - добавит новые записи и обновит существующие (по номеру претензии / номеру партии);
   - выведет статистику импорта.

## Резервное копирование

- Резервная копия БД создаётся автоматически при каждом запуске приложения.
- Дополнительно можно создать копию вручную кнопками **«Резервная копия»** (шапка) или **«Создать резервную копию»** (вкладка «Администрирование»).
- Копии сохраняются в папку `data/backups`.
